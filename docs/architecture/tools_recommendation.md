# Amigo/X4ra Tools & Frameworks Recommendations

## 1. Orchestration & Agent Frameworks
- **LangChain / LangGraph**: For building complex agentic workflows and state management.
- **CrewAI / AutoGPT**: For high-level agent coordination.
- **Python**: Primary language for the orchestrator and agents.

## 2. Local AI (Offline Core)
- **Ollama**: For running Llama 3, Mistral, and other LLMs locally.
- **LocalAI**: Unified API for local models.
- **Whisper**: Local speech recognition.
- **Stable Diffusion (SDXL/SD3)**: Local image generation.

## 3. External AI (Online Boost)
- **OpenAI API**: GPT-4o for advanced reasoning.
- **Anthropic Claude API**: For high-context creative writing and coding.
- **Tavily / Serper**: AI-optimized search APIs for research.

## 4. Memory & Vector Storage
- **ChromaDB / Pinecone**: Vector database for knowledge embeddings.
- **SQLite / PostgreSQL**: Structured data and session logs.
- **Git**: Version control for project files.

## 5. Game Development
- **Unreal Engine 5 / Unity**: Primary game engines.
- **Godot**: Open-source alternative for modularity.
- **Blender**: For 3D asset generation workflows.
